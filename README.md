# 化学三棱镜 · 探究工作台

分析化学三重表征探究工作台的部署站点。十八组可交互模拟器，覆盖教材全部主干：四大滴定、电化学、光谱与质谱、色谱与分离、空间结构、数据与质量。访问：**https://chem-prism.github.io/**

零依赖的静态站点，纯 ES Module + Canvas，无需构建步骤。可直接被教学智能体以 iframe 嵌入。

## 三层同时呈现

每个模拟器都不只画曲线——**三重表征同时显示在屏幕上**：

| 层 | 呈现方式 |
|---|---|
| 符号层 | 曲线图 |
| 宏观层 | 烧杯（液面、指示剂颜色渐变、滴液）／比色皿光路 |
| 微观层 | 粒子视图（离子、分子、配合物）／数轴误差棒 |

这不是装饰。作品的立论是「学生卡在宏观、微观、符号三层之间的转换」，
那么工作台本身就应当把三层都摆出来——**它的存在方式，就是它要教的东西**。

指示剂颜色按两型体比例 `1/(1+10^(pKa−pH))` 连续渐变，
顺带把「变色为什么是一个区间而不是某一点」也讲清楚了。

## 十八组模拟器

| 模拟器 | 波长 | 教学指向 |
|---|---|---|
| 酸碱滴定曲线 | 580 nm | 突跃范围随浓度变化；指示剂必须选在突跃内；化学计量点 ≠ 滴定终点 |
| 分布分数与缓冲 | 500 nm | δ 与总浓度无关、β 与总浓度成正比；缓冲范围由 pKₐ 决定 |
| 沉淀平衡 | 460 nm | 「Ksp 小的先沉淀」的适用边界；不同类型的盐不能直接比较 Ksp |
| EDTA 酸效应 | 530 nm | 条件稳定常数与 pH 的关系；为何要用 K′ 而不是 K |
| 精密度与准确度 | 650 nm | 打靶类比；精密度高 ≠ 准确度高；系统误差不能靠多测消除 |
| 氧化还原滴定 | 620 nm | ΔE°′ 决定突跃；ΔE°′ < 0.35 V 时「能反应」但「不能滴定」 |
| 配位滴定曲线 | 470 nm | 条件稳定常数如何决定 pM 突跃；金属指示剂的选择依据 |
| 分光光度法 | 420 nm | A–c 曲线为何在高浓度弯曲；用偏离段算浓度会错多少 |
| 误差传递 | 560 nm | 加减用绝对误差、乘除用相对误差；用错规则的后果不对称 |
| 电位滴定 | 600 nm | E–V 在终点附近是平的；微分曲线的峰顶才指出终点 |
| 色谱分析法 | 610 nm | α=1 时柱效再高也分不开；R≥1.5 才算分开；流速有最优值 |
| 液液萃取 | 590 nm | 少量多次优于一次全量 |
| 红外光谱 | 640 nm | 官能团区认基团、指纹区辨身份；波数与波长互为倒数 |
| 原子吸收 | 425 nm | 基体效应下标准曲线法失准；标准加入法外推到 A=0 可抵消 |
| 质谱分析法 | 410 nm | 分子离子峰给分子量；同位素峰是卤素指纹（Cl 3:1、Br 1:1） |
| 重量分析法 | 430 nm | 沉淀形式 ≠ 称量形式；换算因数把称量质量换成待测组分质量 |
| 空间构型 | 450 nm | 同样 4 配位，Zn²⁺ 四面体、Cu²⁺ 平面正方形；可拖动旋转 |
| 质量控制图 | 570 nm | 3s 判失控；连续 7 点同侧也异常；受控 ≠ 准确 |

## 任务模式（供智能体派发）

```
https://chem-prism.github.io/?sim=<模拟器>&<参数键值>&task=<任务说明>
```

例：

```
?sim=titration&c=0.001&pka=4.74&task=把酸的浓度从0.10调到0.0010，观察突跃范围怎么变
```

`sim` 指定模拟器，其余键值作为该模拟器的初始参数，`task` 显示为顶部任务条。

各模拟器的参数键：

| sim | 参数键 |
|---|---|
| `titration` | `c`（浓度）、`pka`、`strong`（1=强酸）、`ind`（0=隐藏指示剂带） |
| `distribution` | `pka`、`c`（总浓度）、`ph` |
| `precipitate` | `ccl`（c(Cl⁻)）、`ci`（c(I⁻)） |
| `edta` | `metal`（如 `Ca²⁺`）、`ph`、`c`（金属离子浓度） |
| `precision` | `sigma`（随机误差）、`bias`（系统误差） |
| `redox` | `e1`、`e2`（两电对电位）、`n1`、`n2`、`c` |
| `complexometry` | `metal`、`ph`、`c` |
| `spectrophotometry` | `eps`、`b`、`cmax`、`k`（偏离系数） |
| `propagation` | `a`、`da`、`b`、`db`、`op` |

## 回传机制

学生操作后点「复制实验记录」，生成一段结构化文本（模拟器名、参数、读数、自填结论），粘回智能体对话即可完成「操作 → 报告 → 继续追问」的闭环。无需后端。

## 数值可靠性

`js/chem.js` 为纯函数模块，可脱离浏览器验算：

```bash
node --input-type=module -e "import * as C from './js/chem.js'; console.log(C.equivalencePH(0.1,20,0.1,1.8e-5))"
# → 8.72（与教材一致）
```

滴定曲线用**精确解**（电荷平衡方程二分求根），非教材近似式，因此化学计量点附近与真实一致。已知核对点：0.1 mol/L 强酸滴定突跃 pH 4.30~9.70；浓度每降 10 倍，突跃两端各移 1 个 pH 单位。

# 教师端学情画像看板

访问：**https://chem-prism.github.io/teacher.html**（加 `?demo=1` 可查看示例数据）

数据来源是智雅后台导出的《历史会话详情》表格——**浏览器本地解析，不需要后端**。

看板吃两类数据，都是从同一份导出里解析出来的：

| 来源 | 抽取自 | 贡献的维度 |
|---|---|---|
| 诊断对话 | 【表征层次诊断】+【本次探讨回顾】 | 初始卡点层、认知卡点、涉及知识点、追问轮次 |
| 批改记录 | 【批改数据】块（作业/实验报告批改技能输出） | 错题的卡点层与 MC 归类、涉及知识点 |

两类数据**汇入同一张画像**——它们本就是同一批学生的两种表现。

> 这也意味着：**诊断报告的输出格式就是数据 schema**。修改系统提示词的输出格式时，`js/teacher.js` 的解析规则要同步改。

## 看板内容

| 区块 | 说明 |
|---|---|
| 总览 | 参与人数、诊断对话数、批改记录数、平均追问轮次、最高频卡点层次 |
| 初始卡点分布 | 学生**一开始**卡在宏观 / 微观 / 符号哪一层 |
| 迷思概念排行 | 10 类认知卡点（MC-1~MC-10）的班级分布 |
| 知识点 × 初始卡点层 热力图 | 哪个知识点的哪一层最容易卡住 |
| 学生明细 | 匿名编号 + 初始卡点 + 卡点类型 + 结束状态 |
| 教学建议 | 由数据自动生成的三条建议 |
